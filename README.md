# Bazar Dor (বাজার দর)

A responsive web application built with Next.js and Tailwind CSS to track daily commodity market prices across Bangladesh. It provides real-time market data, price trends, regional market comparisons, category filtering, and secure user authentication.

## Links

- **Live Website:** https://b14-a7-bazar-dor-zjrb.vercel.app/
- **GitHub Repository:** https://github.com/shajibsikder/b14-a7-bazar-dor

## Technologies Used

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- BetterAuth
- Lucide React
- React Hot Toast
- Programming Hero Bazar Dor API

## Key Features

1. **Daily Price Tracking & Trends:** Displays top price risers and fallers compared to yesterday with Bengali numerals and percentage change badges.
2. **Live Infinite Marquee Ticker:** Continuously scrolling price ticker strip below the header showing real-time commodity prices.
3. **Category Filtering & Price Sorting:** Browse products by category and sort items by default, price low-to-high, and price high-to-low based on numeric values.
4. **Protected Product Details & Market Comparison:** Logged-in users can view product summaries, minimum/maximum/average prices, and a comparative table of regional markets.
5. **Authentication & Profile Management:** User registration, login, social auth with BetterAuth, toast notifications, and user profile update functionality.
6. **Responsive Design & Error Handling:** Fully optimized for mobile, tablet, and desktop devices with custom skeleton loading states and a 404 page.
